# World Archaeologist

A Minecraft journal you open in Safari. Records stay in the browser. The site does not read world files, and it does not ask you to install anything.

Live site: https://popcornparty.github.io/minecraft-world-archaeologist/

On an iPhone: open that link, then Share → Add to Home Screen. After the first visit, events still save with no connection.

Export backup downloads a file you can keep in the Files app. Import backup reads that file back. Replace asks before it deletes what is already stored on the phone.

The sentence box uses fixed rules, not a language model. Edit the suggestion before saving.
